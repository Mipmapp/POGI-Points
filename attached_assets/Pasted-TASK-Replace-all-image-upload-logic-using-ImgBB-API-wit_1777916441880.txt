TASK: Replace all image upload logic using ImgBB API with Cloudinary.

GOAL:
Migrate the entire project from ImgBB to Cloudinary for image upload, storage, and delivery, while keeping existing functionality intact.

STEPS:

1. INSTALL DEPENDENCIES

* Install Cloudinary SDK:
  npm install cloudinary multer multer-storage-cloudinary

2. ENVIRONMENT VARIABLES

* Add the following to .env:
  CLOUDINARY_CLOUD_NAME=your_cloud_name
  CLOUDINARY_API_KEY=your_api_key
  CLOUDINARY_API_SECRET=your_api_secret

3. SETUP CLOUDINARY CONFIG

* Create a config file (e.g., config/cloudinary.js):

  * Import cloudinary
  * Configure using environment variables
  * Export the configured instance

4. REMOVE IMGBB LOGIC

* Find all usages of ImgBB API (fetch/axios calls, API keys)
* Remove:

  * ImgBB upload endpoints
  * API keys
  * Related helper functions

5. IMPLEMENT IMAGE UPLOAD WITH CLOUDINARY

* Use multer + multer-storage-cloudinary for handling uploads
* Create an upload middleware
* Store images in a folder (e.g., "uploads/")
* Ensure images are auto-optimized (format: webp, quality auto)

6. UPDATE BACKEND ROUTES

* Modify existing upload routes:

  * Replace ImgBB upload logic with Cloudinary upload
  * Return secure_url instead of ImgBB URL

7. UPDATE DATABASE STORAGE

* Ensure database stores:
  {
  imageUrl: cloudinary.secure_url,
  public_id: cloudinary.public_id
  }

8. UPDATE FRONTEND

* Ensure frontend uses returned Cloudinary URLs
* Remove any ImgBB-specific response handling

9. ADD DELETE FUNCTIONALITY

* Implement image deletion using Cloudinary public_id

10. TESTING

* Test:

  * Upload image
  * Retrieve/display image
  * Delete image
* Ensure no ImgBB references remain

CONSTRAINTS:

* Do not break existing features
* Keep code clean and modular
* Add comments where changes are made
* Ensure mobile compatibility is preserved

OUTPUT:

* Updated backend + frontend code
* Clean migration with no ImgBB dependency remaining
