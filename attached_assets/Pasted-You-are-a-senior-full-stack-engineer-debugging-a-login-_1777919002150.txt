You are a senior full-stack engineer debugging a login authentication flow issue.

PROBLEM:
- When the user clicks the LOGIN button:
  1. A loading screen appears
  2. After loading finishes, the user is NOT logged in yet
  3. The user must click LOGIN a second time before being successfully authenticated

EXPECTED BEHAVIOR:
- User clicks LOGIN ONCE
- Show loading state while processing authentication
- After successful login:
  - User is automatically redirected/logged in
  - No second click should be required

---

TASK: DEBUG ROOT CAUSE

1. Trace the full login flow:
   - Login button handler
   - API request / authentication call
   - State updates (auth state, user state)
   - Routing/navigation after login
   - Loading state management

2. Identify issues such as:
   - Missing async/await in login function
   - Navigation happening before login completes
   - Auth state not updating before redirect
   - useState or global state not persisting login result
   - Component re-render resetting login state
   - Token/session not stored correctly (localStorage/sessionStorage/cookies)

3. Check if:
   - First click only triggers loading UI but does NOT complete authentication
   - Second click is actually the one that finally triggers valid auth state

---

TASK: FIX THE ISSUE

Apply proper fixes such as:
- Ensure login function is fully async and awaited
- Ensure authentication completes BEFORE navigation
- Store auth state correctly (context/global state/local storage if needed)
- Prevent duplicate login triggers
- Disable login button while loading
- Ensure loading screen is tied to real API state, not just click event

---

EXPECTED FLOW AFTER FIX:

1. User clicks LOGIN once
2. Button becomes disabled + loading starts
3. API authenticates user
4. Auth state updates successfully
5. User is redirected automatically
6. No second click needed

---

OUTPUT FORMAT:

1. ROOT CAUSE
2. FILES AFFECTED
3. FLOW BREAKDOWN (what happens on first click)
4. FIX IMPLEMENTED (before/after code)
5. FINAL CORRECT LOGIN FLOW

---

IMPORTANT:
- Do NOT just change UI
- Focus on async flow, state management, and authentication lifecycle
- Ensure fix is stable and production-ready
