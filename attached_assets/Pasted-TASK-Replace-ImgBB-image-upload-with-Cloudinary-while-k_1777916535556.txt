TASK: Replace ImgBB image upload with Cloudinary while keeping MongoDB as the database for storing image references.

GOAL:
Migrate all image uploads from ImgBB API to Cloudinary, and store the resulting image URL and metadata inside MongoDB.

REQUIREMENTS:

1. INSTALL DEPENDENCIES

* Install:
  npm install cloudinary multer multer-storage-cloudinary

2. ENVIRONMENT VARIABLES

* Add to .env:
  CLOUDINARY_CLOUD_NAME=your_cloud_name
  CLOUDINARY_API_KEY=your_api_key
  CLOUDINARY_API_SECRET=your_api_secret

3. CLOUDINARY SETUP

* Create config/cloudinary.js
* Configure Cloudinary using environment variables
* Export the configured cloudinary instance

4. REMOVE IMGBB

* Remove all ImgBB API calls, keys, and helper functions
* Ensure no ImgBB references remain in backend or frontend

5. IMAGE UPLOAD MIDDLEWARE

* Implement multer + multer-storage-cloudinary
* Store images in a folder (e.g., "app_uploads")
* Apply optimization:

  * format: "webp"
  * quality: "auto"

6. UPDATE UPLOAD ROUTES

* Replace ImgBB upload logic with Cloudinary upload
* On upload success, return:
  {
  imageUrl: result.secure_url,
  public_id: result.public_id
  }

7. STORE IN MONGODB

* Update schema/model to include:
  imageUrl: String,
  public_id: String

* When saving a record:

  * Save Cloudinary secure_url into imageUrl
  * Save public_id for future deletion

Example:
{
name: "User",
imageUrl: "https://res.cloudinary.com/.../image.webp",
public_id: "app_uploads/abc123"
}

8. FRONTEND UPDATE

* Use imageUrl from API response
* Remove any ImgBB-specific handling

9. DELETE FEATURE

* Add endpoint to delete image:

  * Use cloudinary.uploader.destroy(public_id)
  * Remove or update record in MongoDB

10. TESTING

* Upload image → verify stored in Cloudinary
* Check MongoDB → correct URL stored
* Display image → loads correctly
* Delete image → removed from Cloudinary and MongoDB updated

CONSTRAINTS:

* Keep MongoDB as the main database
* Do NOT store image binary in MongoDB
* Only store URL + public_id
* Keep existing features working

OUTPUT:

* Updated backend routes
* Updated MongoDB schema
* Clean migration with Cloudinary fully integrated
