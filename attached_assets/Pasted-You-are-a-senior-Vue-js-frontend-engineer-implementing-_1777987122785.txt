You are a senior Vue.js frontend engineer implementing a global theming system.

GOAL:
- Convert the entire app to use a centralized theme system
- Apply a CCS-based theme
- Ensure changes are reversible and maintainable

---

PROJECT CONTEXT:
- Framework: Vue.js
- App has multiple components (dashboard, sidebar, modals, etc.)
- Colors are currently hardcoded or inconsistent

---

TASK 1: GLOBAL SCAN

Scan ALL Vue files (.vue), CSS, and JS for:
- Hardcoded colors (#hex, rgb, hsl)
- Inline styles
- Tailwind classes (if used)

List:
- File name
- Code snippet
- Classify as:
  [PRIMARY] [SECONDARY] [BACKGROUND] [TEXT] [BORDER]

DO NOT MODIFY YET.

---

TASK 2: CREATE THEME SYSTEM

Create a global CSS file (e.g., /src/styles/theme.css):

:root {
  --primary: ORIGINAL_COLOR;
  --secondary: ORIGINAL_COLOR;
  --background: ORIGINAL_COLOR;
  --surface: ORIGINAL_COLOR;
  --text: ORIGINAL_COLOR;
}

[data-theme="ccs"] {
  --primary: CCS_PRIMARY;
  --secondary: CCS_SECONDARY;
  --background: CCS_BACKGROUND;
  --surface: CCS_SURFACE;
  --text: CCS_TEXT;
}

Import this globally in main.js or App.vue

---

TASK 3: APPLY CCS COLORS

Use a green-based palette inspired by CCS logo:
- Primary: deep green
- Secondary: lighter green
- Background: soft light green
- Text: dark readable tone

---

TASK 4: BULK REFACTOR

Replace ALL hardcoded colors:

Example:
color: #36b37e → color: var(--primary)

Ensure:
- No inline hardcoded colors remain
- All components use CSS variables

---

TASK 5: VUE THEME TOGGLE

Create a composable or method:

function setTheme(theme) {
  document.documentElement.setAttribute("data-theme", theme)
  localStorage.setItem("theme", theme)
}

On app load:
- Read from localStorage
- Apply saved theme

---

TASK 6: ADD TO UI

Optionally:
- Add a toggle button (e.g., in settings or sidebar)
- Allow switching between:
  - "default"
  - "ccs"

---

TASK 7: VALIDATION

Ensure:
- UI looks consistent across all pages
- No broken layouts
- Good contrast and readability
- Works on mobile and desktop

---

OUTPUT FORMAT:

1. THEME FILE CREATED
2. CCS COLOR PALETTE USED
3. FILES MODIFIED
4. BEFORE vs AFTER EXAMPLES
5. HOW TO SWITCH / REVERT THEME

---

IMPORTANT:

- DO NOT modify business logic
- ONLY change styling
- Make everything reversible
- Work in small batches
