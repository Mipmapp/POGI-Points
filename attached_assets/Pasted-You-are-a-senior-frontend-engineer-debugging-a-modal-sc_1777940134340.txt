You are a senior frontend engineer debugging a modal scroll issue in a mobile-responsive web app.

PROBLEM (BASED ON UI):
- A Terms & Conditions modal is displayed (centered with rounded corners)
- The modal contains long content (text with bullet points)
- When scrolling:
  ❌ The BACKGROUND page scrolls
  ❌ The modal content does NOT scroll properly
- Expected:
  ✅ Only the modal content should scroll
  ✅ Background must remain fixed

---

TASK 1: ANALYZE MODAL STRUCTURE

1. Locate the T&C modal component and inspect:
   - Parent container (overlay/backdrop)
   - Modal wrapper
   - Modal content section (where text is)

2. Identify issues such as:
   - Modal content missing `overflow-y: auto`
   - Modal height not constrained (no max-height)
   - Parent container not properly structured
   - Body still scrollable while modal is open

---

TASK 2: FIND ROOT CAUSE

Check for:
- Missing scroll container inside modal
- `overflow: hidden` or incorrect overflow usage
- Modal using full height without scroll handling
- No scroll lock applied to `<body>`
- Z-index or layering issues

Clearly explain WHY scrolling goes to background instead of modal.

---

TASK 3: APPLY FIX (PRECISE, MINIMAL)

Implement the following:

1. LOCK BACKGROUND SCROLL
When modal is open:
- Apply:
  document.body.style.overflow = "hidden"

When modal is closed:
- Restore:
  document.body.style.overflow = "auto"

---

2. FIX MODAL SCROLL CONTAINER

Ensure modal content area has:

- max-height: 70vh or 80vh
- overflow-y: auto
- smooth scrolling

Example:
.modal-content {
  max-height: 75vh;
  overflow-y: auto;
}

---

3. ENSURE PROPER STRUCTURE

- Backdrop:
  position: fixed;
  inset: 0;
  display: flex;
  align-items: center;
  justify-content: center;

- Modal:
  should NOT take full height without scroll control

---

4. MOBILE FIX (IMPORTANT)

Ensure:
- Touch scrolling works inside modal
- Add:
  -webkit-overflow-scrolling: touch;

Check that no `touchmove` or `preventDefault()` is blocking scroll.

---

TASK 4: VALIDATION

Test and confirm:
- Scroll inside modal works smoothly
- Background does NOT move
- Works on mobile swipe (center, top, bottom)
- No UI elements are broken (buttons like "I Understand & Close")

---

OUTPUT FORMAT:

1. ROOT CAUSE
2. AFFECTED FILES
3. BEFORE vs AFTER CODE
4. WHY FIX WORKS
5. MOBILE TEST RESULT

---

IMPORTANT:
- Do NOT redesign UI
- Do NOT remove modal
- Only fix scroll behavior cleanly and safely
