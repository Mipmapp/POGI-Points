You are a senior frontend engineer fixing a modal scrolling issue in a web application.

PROBLEM:
- A Terms & Conditions (T&C) modal is open on top of the page
- When the user scrolls:
  - The BACKGROUND PAGE scrolls instead of the modal content
- Expected behavior:
  - Only the modal content should scroll
  - The background page must be locked (no scrolling)

---

TASK 1: IDENTIFY ROOT CAUSE

Scan the codebase and check:
1. Modal implementation (T&C modal component)
2. CSS properties affecting scroll:
   - overflow
   - height (100vh issues)
   - position: fixed/absolute
   - z-index layering
3. JavaScript logic that handles modal open/close:
   - body scroll locking (or missing scroll lock)
   - event listeners for wheel/touchmove
   - preventDefault usage

Find why background scrolling is still active.

---

TASK 2: FIX THE ISSUE

Implement proper modal scroll behavior:

A. When modal opens:
- Disable background scrolling using one of:
  - document.body.style.overflow = "hidden"
  - or add a class like "no-scroll" to body

B. When modal closes:
- Restore scrolling:
  - document.body.style.overflow = "auto"

C. Ensure modal content is scrollable:
- Modal container should have:
  overflow-y: auto
  max-height: 80vh or 100vh
  height: auto

D. Ensure proper structure:
- Modal backdrop covers full screen
- Modal content is centered but scrollable independently

---

TASK 3: MOBILE SUPPORT

Ensure:
- touch scrolling works inside modal only
- background does NOT scroll on swipe
- fix any touch-action or passive event issues

---

EXPECTED RESULT:

- User opens T&C modal
- Background page is completely locked
- Only modal content scrolls
- Works on desktop + mobile (touch swipe included)

---

OUTPUT FORMAT:

1. ROOT CAUSE
2. AFFECTED FILES
3. BEFORE vs AFTER CODE FIX
4. EXPLANATION OF FIX
5. CONFIRMATION OF MOBILE + DESKTOP BEHAVIOR

---

IMPORTANT RULES:
- Do NOT remove modal UI
- Do NOT disable scrolling globally permanently
- Only lock scroll when modal is open
- Keep solution production-safe
